<h2><a href="https://www.geeksforgeeks.org/problems/max-sum-submatrix2725/1">Max Sum Submatrix Queries</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given a matrix <strong>mat[][]</strong> of size <strong>n × m</strong> and a query matrix <strong>queries[][]</strong> of size <strong>q × 2</strong>, where each query queries[i] = [a, b] represents the dimensions of a submatrix, find the maximum sum among all contiguous a × b submatrices for each query.</span></p>
<p><span style="font-size: 18px;"><strong>Examples :</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>mat[][] = [[1, 2, 3, 9], [4, 5, 6, 2], [8, 3, 2, 6]], queries[][] = [[1, 1], [2, 2], [3, 3]]<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/929760/Web/Other/blobid0_1781592716.webp" width="214" height="142"></span>
<strong style="font-size: 18px;">Output:</strong><span style="font-size: 18px;"> [9, 20, 38]<br></span><strong style="font-size: 18px;">Explanation:</strong><span style="font-size: 18px;"><br></span><span style="font-size: 18px;">For 1 × 1, the maximum submatrix sum is 9.
For 2 × 2, the possible submatrix sums are 12, 16, 20, 20, 16, 16. The maximum is 20.
For 3 × 3, the possible submatrix sums are 34 and 38. The maximum is 38.
Therefore, the answer is [9, 20, 38].</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>mat[][] = [[1, 2, 3, 9], [4, 5, 6, 2], [8, 3, 2, 6]], queries[][] = [[3,2]]</span> <br><span style="font-size: 18px;"><strong>Output:</strong> [28]</span>
<span style="font-size: 18px;"><strong>Explanation: </strong></span><span style="font-size: 18px;">For a = 3 and b = 2, the possible 3 × 2 submatrices have sums 23, 21, and 28. The maximum is 28.</span></pre>
