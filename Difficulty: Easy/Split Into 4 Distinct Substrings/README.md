<h2><a href="https://www.geeksforgeeks.org/problems/split-the-string2424/1">Split Into 4 Distinct Substrings</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given a string <strong>s</strong>, determine whether it can be split into <strong>four</strong> non-empty <strong>substrings</strong> such that all four substrings are pairwise <strong>distinct</strong>.</span></p>
<p><span style="font-size: 14pt;">Return <strong>true</strong> if such a split exists, otherwise return <strong>false</strong>.</span></p>
<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 14pt;"><strong>Input: </strong>s = "geeksforgeeks"
<strong>Output: </strong>true
<strong>Explanation: </strong>One possible split is: "geeks" , "for" , "gee" , "ks"<br>All four substrings are non-empty and distinct, so the output is true.<br></span></pre>
<pre><span style="font-size: 14pt;"><strong>Input: </strong>s = "aaabb" 
<strong>Output: </strong>false
<strong>Explanation: </strong>There is no way to split the string into four non-empty substrings such that all four substrings are distinct. Therefore, the output is false.</span></pre>
<p><span style="font-size: 14pt;"><strong>Constraints:</strong><br>1 ≤ |s| ≤ 10<sup>5<br></sup>s consists only of lowercase English letters.</span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Strings</code>&nbsp;
